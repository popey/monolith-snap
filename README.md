## Monolith

Bundle any web page into a single HTML file. Monolith not only saves the target document, it embeds CSS, image, and JavaScript assets all at once, producing a single HTML5 document.

This snap is a community-maintained unofficial build of [monolith](https://github.com/Y2Z/monolith).

[![Get it from the Snap Store](https://snapcraft.io/static/images/badges/en/snap-store-black.svg)](https://snapcraft.io/monolith)

## Install

Install on any [supported Linux](https://snapcraft.io/docs/installing-snapd) distribution:

```
snap install monolith
```
